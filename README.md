**Adaptive travel planning powered by real-world information.**

A travel-planning application that combines itinerary generation, weather
information, travel news, and risk analysis to help users make better travel
decisions.

`Python` `FastAPI` `AI APIs` `Weather APIs` `Travel Intelligence`

---

### 💸 GroupTrip Ledger
**Making group travel expenses easier to manage.**

An expense-management application designed for group trips. It helps travelers
record shared expenses, track payments, calculate individual contributions,
and understand who owes whom.

`Python` `Flask` `SQLite` `JavaScript` `ReportLab`

---

### 🧠 BrainXAI
**Machine learning applied to student placement prediction.**

A student placement prediction system that uses student-related features and a
machine learning model to estimate placement outcomes.

`Python` `Flask` `Scikit-learn` `Random Forest`

---

### 📱 SkillSync

An Android application focused on helping users connect their skills and
learning journey with relevant opportunities.

`Java` `Android Studio` `Firebase`
